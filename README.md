# Phishing Awareness Training Module

## Overview

This project is an online phishing awareness training module designed to educate users about common phishing and social engineering techniques.

The module uses simple explanations, examples, and an interactive quiz to help users recognize suspicious messages, fake websites, and social engineering attempts.

## Features

* Phishing awareness training
* Email phishing awareness
* Social engineering awareness
* Interactive knowledge-check quiz
* JavaScript-based quiz scoring
* Simple and responsive web interface
* Navigation between training sections

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Use

1. Open `index.html` in a web browser.
2. Navigate through the different training sections.
3. Read the phishing, email security, and social engineering lessons.
4. Complete the quiz.
5. Click **Submit Answers** to view your score.

## Purpose

The purpose of this project is to promote cybersecurity awareness and help users identify common phishing and social engineering warning signs before interacting with suspicious messages or websites.
